# Plan and Implement

Keep the active record in `work/{short-name}/plan.md` and `work/{short-name}/checklist.md`. Follow repository instructions for code, tests, and Git. Put work discovered outside the agreed scope in `todo/`.

Read the reference for the current phase, then any template it links. Resume from the work stream's actual state:

- To start or revise a plan, or turn an agreed plan into work items, read [Planning](references/plan.md).
- For `next work/{short-name}/checklist.md` or review feedback on implementation, read [Implementation](references/implement.md).
